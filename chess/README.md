# Шахматный тренажёр

Веб-приложение (MVP) для тренировки видения доски и заучивания дебютов и гамбитов.
React + Vite + TypeScript, Tailwind CSS, [chess.js](https://github.com/jhlywa/chess.js) и
[react-chessboard](https://github.com/Clariity/react-chessboard). Тёмная тема в стиле шахматных сайтов,
адаптивная вёрстка (на телефоне — нижняя навигация и ходы касанием).

## Запуск

```bash
cd chess
npm install
npm run dev        # http://localhost:5173
npm test           # проверка PGN-парсера и всей базы дебютов
npm run build      # сборка в dist/ (относительные пути — работает в любой подпапке)
```

## Что внутри

- **Главная** — серия дней подряд, рекорды и точность в координатах, сколько линий выучено и что пора
  повторить, график тренировок за две недели.
- **Тренажёр координат** — пустая доска, случайная клетка крупно поверх доски и в панели.
  Режимы «На время» (30/60/120 с) и «Серия» (10/20/40 клеток, 2–10 с на клетку, не успел — ошибка).
  Белые/чёрные снизу или случайно, подписи клеток по желанию. В конце — верно/ошибки, точность,
  среднее время, список промахов и рекорд режима. Карта ошибок подсвечивает «трудные» клетки.
- **Дебютный тренажёр**
  - библиотека из 42 курсов (16 за белых, 26 за чёрных, включая два сборника ловушек), фильтры и поиск;
  - над и под доской — взятые фигуры каждой стороны, перевес («+3») и очки материала;
  - страница курса: идеи дебюта, список линий со статусом, просмотр любой линии на доске с комментариями;
  - **Изучение** — стрелка показывает ход, комментарий объясняет идею;
  - **Тренировка** — компьютер отвечает ходами соперника из базы; неверный ход возвращается назад,
    затем подсказка (какой фигурой ходить), затем стрелка. Результат идёт в интервальное повторение
    (уровни 0–6, повтор через 20 ч / 3 / 7 / 16 / 35 дней);
  - **Свой курс** — импорт PGN (текст или файл; несколько партий, варианты в скобках, комментарии) или
    ввод ходов на доске за обе стороны с комментариями; экспорт любого курса в PGN.
- **Настройки** — цвет доски, подписи, анимация, скорость ответа компьютера, резервная копия
  (экспорт/импорт JSON), сброс прогресса.

Весь прогресс, рекорды и пользовательский репертуар хранятся в `localStorage` (ключи `chess-trainer/*`).

## База дебютов

`src/data/courses/` — по файлу на курс. Линия записывается обычным PGN, комментарий в фигурных скобках
относится к ходу перед ним:

```ts
{ id: 'fritz', name: 'Вариант Фрица: 5...Кd4', pgn: `1.e4 e5 2.Nf3 Nc6 ... 5.exd5 Nd4 {Вариант Фрица.} 6.c3 ...` }
```

| За белых | За чёрных: защиты | За чёрных: гамбиты |
|---|---|---|
| Итальянская партия, Испанская партия, Шотландская партия, Лондонская система, Ферзевый гамбит, Гамбит Эванса, Атака 4.Кg5 / «Фрид Ливер», Шотландский гамбит, Гамбит Гёринга, Датский гамбит, Венская партия и Венский гамбит, Королевский гамбит, Гамбит Смит-Морра, Гамбит Блэкмара — Димера, Гамбит Стаунтона, **Ловушки за белых** | Против 1.e4: Каро — Канн, Скандинавская, Французская, Сицилианская (Найдорф, дракон, ускоренный дракон), Алехина, Пирца, Русская партия, Филидора. Против 1.d4: Староиндийская, Грюнфельда, Нимцовича и новоиндийская, Отказанный ферзевый гамбит, Славянская, Голландская | Гамбит Стаффорда, Гамбит Фрома, Будапештский гамбит, Контргамбит Альбина, Волжский гамбит, Гамбит Шлимана, Атака Маршалла, Контратака Трэкслера, Против королевского гамбита: 2...d5, **Ловушки за чёрных** |

Всего 440 линий, включая учебные ловушки (мат Легаля, Ноев ковчег, «слоновья» ловушка, удочка,
ловушки Кенингера и Ласкера, сибирская ловушка и др.). Гамбит Энглунда за чёрных не включён — движок
оценивает его почти в −3,5, зато его опровержение есть в курсах «Лондонская система» и «Ферзевый гамбит». Как проверялась база:

1. главные линии сверены со статьями Wikipedia и Wikibooks «Chess Opening Theory»;
2. каждая позиция прогнана через облачную базу движка [chessdb.cn](https://www.chessdb.cn/): ходы ученика не
   уступают лучшему ходу движка больше чем ~0,6 пешки (исключения — тематические ходы рискованных
   гамбитов, это отмечено в комментариях), ошибки соперника встречаются только в линиях-ловушках;
   несколько популярных, но опровергнутых продолжений заменены (например, в «Фрид Ливере» 9.O-O вместо 9.a3);
3. `npm test` проверяет, что все ходы легальны, id уникальны, а репертуар согласован —
   в одной позиции ученик всегда делает один и тот же ход (кроме сборников ловушек: там линии из разных
   дебютов намеренно расходятся, и тренажёр ждёт ход именно выбранной ловушки).
